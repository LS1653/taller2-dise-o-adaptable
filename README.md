#  Zenless Zone Zero — Página Web

Página web desarrollada como proyecto académico para practicar el diseño adaptable (Responsive Design), la estructura de páginas web y la migración de un proyecto tradicional a un entorno moderno utilizando **Vite** y **Tailwind CSS**.

La página está inspirada visualmente en el videojuego **Zenless Zone Zero (ZZZ)** y presenta diferentes secciones relacionadas con su mundo, historia, personajes, sistema de combate y Bangboo.

##  Tecnologías utilizadas

- **HTML5** — Estructura y contenido de la página.
- **CSS3** — Estilos personalizados, diseño responsive y animaciones.
- **JavaScript** — Interactividad y comportamiento de la página.
- **Vite** — Herramienta de desarrollo y compilación del proyecto.
- **Tailwind CSS** — Utilidades CSS para facilitar la construcción del diseño.
- **Git & GitHub** — Control de versiones y almacenamiento del proyecto.
- **GitHub Pages** — Despliegue de la página web.

Vite proporciona un servidor de desarrollo rápido y un sistema de compilación para generar los archivos optimizados del proyecto. :contentReference[oaicite:0]{index=0}

Tailwind CSS permite utilizar clases utilitarias directamente en el HTML y generar los estilos necesarios durante el proceso de compilación. :contentReference[oaicite:1]{index=1}

##  Sobre el proyecto

El proyecto comenzó como una página desarrollada utilizando principalmente:

- HTML
- CSS
- JavaScript

Posteriormente, se realizó una migración a **Vite + Tailwind CSS**, manteniendo gran parte de los estilos CSS originales y complementándolos con clases utilitarias de Tailwind.

El objetivo principal fue aprender a trabajar con:

- Herramientas modernas de desarrollo web.
- Diseño responsive.
- Vite y su sistema de desarrollo.
- Tailwind CSS.
- JavaScript para interacción.
- Organización de archivos.
- Control de versiones con Git.
- Despliegue mediante GitHub Pages.

##  Secciones de la página

La página está organizada en las siguientes secciones:

###  World

Presentación del mundo de Zenless Zone Zero, acompañada de contenido audiovisual.

###  History

Sección dedicada al contexto e historia del universo del juego.

###  Characters

Galería horizontal de personajes.

Incluye:

- Desplazamiento horizontal.
- Botones de navegación.
- Arrastre con mouse.
- Soporte para dispositivos táctiles.
- Diseño adaptable.

###  Combat

Sección dedicada al sistema de combate, acompañada de contenido audiovisual.

###  Bangboo

Presentación de diferentes Bangboo mediante tarjetas informativas.

###  Footer

Información final y créditos del proyecto.
